# claude-shared-memory

**Одна пам'ять для Claude Code, чату claude.ai і Cowork** — лише файли, скіли й конектор Google Диска. Без серверів, без платних сервісів, без коду в хмарі.

🇬🇧 [English version](README.md)

## Навіщо
Claude Code на ноутбуці знає ваші проєкти, правила й історію. Відкриваєте claude.ai на телефоні — і там нічого цього нема. Цей набір робить так, що кожен Claude на початку розмови читає ту саму пам'ять, а наприкінці повертає те, що вирішили.

## Як це працює (за 20 секунд)
- **Комп'ютер — джерело правди**: Markdown-файли в папці, яку ви відкриваєте в Claude Code (`CLAUDE.md`, `JOURNAL.md`, `memory/MEMORY.md`, `docs/CONTEXT.md` кожного проєкту).
- Після кожної завершеної задачі Claude Code (скіл **task-summary**) кладе свіжий Google-документ `MEMORY` у папку Диска `Claude-memory`.
- Кожна розмова в claude.ai чи Cowork (скіл **shared-memory**) спершу читає `MEMORY`, а наприкінці кладе підсумок на одну сторінку в `Claude-memory/INBOX`.
- Claude Code переносить INBOX у ваші файли, позначає кожен запис ✅ і переносить в `archive`. Нічого не видаляється.

Подробиці, схема й обмеження, на які ми натрапили: [docs/how-it-works.uk.md](docs/how-it-works.uk.md).

## Що всередині
| Папка | Що |
|---|---|
| `skills/` | скіл для claude.ai `shared-memory` (сам протокол) |
| `claude-code/` | кладеться в папку Claude Code: шаблон `CLAUDE.md`, скіл `task-summary`, шаблони журналу й пам'яті |
| `sync/` | необов'язкова автокопія для Windows кожні 30 хв: закрите сховище GitHub + дзеркало на Google Диску (`install-sync.ps1` ставить її в Планувальник) |
| `tools/` | `build-skill-zips.py` — пакує скіли в zip, які приймає claude.ai |
| `docs/` | [як це працює](docs/how-it-works.uk.md), [налаштування](docs/setup.uk.md) |

## Швидкий старт
1. Прочитайте [docs/setup.uk.md](docs/setup.uk.md) (≈30 хв). Або доручіть більшу частину Claude Code: відкрийте його в порожній папці й вставте
   `Налаштуй мені набір claude-shared-memory з https://github.com/kuzubis/claude-shared-memory за його docs/setup.uk.md. Перед усім, що створює облікові записи, сховища чи задачі за розкладом, питай мене.`
2. У claude.ai: завантажте zip скіла `shared-memory`, увімкніть конектор Google Drive, вставте один абзац в особисті налаштування.
3. Перевірка: спитайте новий чат про те, що знає лише ваша пам'ять.

## Наповнити пам'ять з першого дня
Порожня пам'ять наповнюється під час роботи. Щоб почати з повною, пройдіть інтерв'ю із сусіднього набору **[claude-deep-context](https://github.com/kuzubis/claude-deep-context)**: Claude поставить 14 блоків питань і збере скіли `my-profile` і `my-company` — вони ж стануть запасним варіантом, коли Диск недоступний.

## Що потрібно
- Тариф claude.ai зі Скілами й Конекторами; Claude Code.
- Обліковий запис Google (той самий у claude.ai і Claude Code).
- Windows — лише для необов'язкових скриптів `sync/` (решта працює будь-де).

## Приватність
Файли пам'яті йдуть на Google Диск (і на GitHub, якщо користуєтеся `sync/`). Тримайте сховище GitHub **закритим** і ніколи не пишіть у пам'ять паролі, номери карток чи паспортні дані. Автокопія не бере `.env`, ключі й файли сесій.
